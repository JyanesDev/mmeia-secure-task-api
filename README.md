# Secure Task API

Task Management API construida siguiendo [MMEIA](https://github.com/JyanesDev/MMEIA-METHODOLOGY-V2) — segundo Reference Project del catálogo de `05_Reference_Projects` (`02_API`).

Demuestra autenticación (JWT + refresh tokens) y, sobre todo, autorización por propietario: no basta con saber quién eres, el sistema debe decidir qué puedes hacer.

Ver `spec.md`, `requirements.md` y `tasks.md` para la especificación completa antes de cualquier línea de código (FASE 8, Spec antes de Build).
